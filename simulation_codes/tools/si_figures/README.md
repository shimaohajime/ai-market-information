# Supplementary-figure utilities

These scripts preserve the figure-construction and numerical-audit logic for supplementary figures S7--S10.

They are included as source documentation, not as a standalone reproduction target. Several scripts require archived path-level experiment inputs in `recovered/` or `data/`. Those inputs, along with generated figure files, are intentionally excluded from this repository because this release contains only executable source, configurations, and small aggregate summaries.

The released aggregate tables are in `../../results/aggregate/`. Use the simulation directories for runnable population and neural experiment code. Do not expect these utilities to run from a clean clone without the separately archived inputs.
