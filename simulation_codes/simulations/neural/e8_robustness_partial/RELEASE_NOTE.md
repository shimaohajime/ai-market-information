# Release note

The Python source in this directory was recovered from an archived research experiment. The original README/PROTOCOL was written for a complete experiment archive and may reference weights, raw synthetic input banks, or output files that are **not included** in this lightweight public-code preparation.

- Original Python source is preserved in its relative directory structure.
- Small aggregate files needed for specific tests or figures may be present; others are in `../../../results/aggregate/` (path relative to the repository root may differ by study).
- Neural checkpoints (`.pt`) were excluded; any test or command that loads them requires regeneration or an authorized external archive.
- Results in the paper are not claimed to have been recomputed from scratch in this release staging.

**E8 is incomplete:** 45 members of the original source archive were unavailable. Do not represent this subfolder as a full E8 reproduction.
